Licensing

Clear rules, so buying and switching machines is stress-free.

🎟️

License code is your credential

No account, no password. Enter your license code under "Settings → Activate" in the app to manage your license.

💻

Single machine

One subscription binds one computer at a time. To switch, "deactivate this machine" on the old one first, then activate on the new one.

⏳

Renewals extend

Renew before expiry and time stacks onto your current expiry date, not the payment date. Enter the new code on your already-activated computer.

🔄

Transfer quota

Up to 6 machine transfers per rolling year. Reinstalling or re-activating on the same machine doesn't count.

📶

No forced connection

A connection is only needed for first activation, renewal and transfer; otherwise the local record applies and it works offline.

🧩

Consistent features

The full version includes all editing, export and plugin capabilities. Refer to the in-app About page for version details.

Purchase FAQ

Can I try it free first?

Yes. Download the app to try local editing, then buy a license code to unlock the full version.

How many computers can one code activate?

One computer at a time. To switch, deactivate on the old machine first, then activate on the new one; up to 6 transfers per rolling year.

Does renewal count from payment or expiry date?

Renewing before expiry stacks onto the current expiry; if already expired it starts from now. Enter the new code on the activated computer.

Do I need to stay online?

No. Only first activation, renewal and transfer need a connection; it works offline otherwise.

Can I get an invoice?

Yes, please mention invoicing when purchasing via the contact above.
