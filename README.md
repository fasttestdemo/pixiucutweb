# PixiuCut

PixiuCut 是一款面向短视频创作者的**本地桌面视频剪辑器**。画面实时预览与导出，多轨编辑、素材、字幕、特效全部在你的电脑上完成，不依赖云端，素材不离开本机——快、稳、私密。

- 支持多任务同时渲染导出视频
- 支持 PixiuCut MCP，为本地 AI 模型构建一个视频剪辑工作台
- 当前主力平台为 **Windows x64**

官网：https://pixiucut.meitool.cn/

## 主要功能

### 多轨时间线
视频、音频、字幕多轨独立叠层。支持片段移动、跨轨、裁剪、分割、删除，拖拽吸附与碰撞检测，标尺缩放与撤销 / 重做。

### 实时预览与画布
编辑即时反馈，预览帧直推界面。选中片段可在画布上直接平移、缩放、旋转，与效果面板双向同步。

### 字幕与特效
文本字幕添加与样式编辑，视频变换 / 裁剪 / 变速，音频参数调节，字幕可在预览画布上直接选中与变换。支持本地字幕识别与字幕智能优化。

### 草稿箱与任务中心
新建、打开、重命名、删除草稿；编辑中自动保存、关窗落盘、异常快照恢复。任务中心查看导出队列，重启后仍可续跑。

### 灵活导出
编辑器内单稿导出，分辨率、码率等参数可配；首页多选批量导出，共享配置与输出目录，任务中心串行执行。正式版支持批量视频导出。

### 插件化生态
通过插件扩展功能，支持本地安装与插件管理。第三方「草稿转换器」插件读取草稿并产出新草稿，开发者可基于官方 SDK 快速开发自己的插件，实现视频编辑的无限可能。

### MCP 支持
通过 PixiuCut MCP，让本地 AI 模型接入并操作剪辑动作，为本地 AI 构建一个视频剪辑工作台。

## 为短视频而生

专注短视频创作，竖屏优先（默认 9:16），同时支持 16:9、1:1、4:3 等比例。所有编解码、合成、导出都在本机完成，无需上传、无需等待云端排队。剪辑与渲染进程分离，可边剪辑边渲染，多任务同时导出。

## 版本与授权

- **免费版**：基础功能（多轨编辑、导出等）、本地字幕识别、MCP 支持，不限制导出次数。
- **正式版**（月卡 / 季卡 / 年卡）：在免费版基础上，解锁批量视频导出、字幕智能优化、插件安装与使用。

授权以激活码为凭证，不注册、不强制联网：

- **单机使用**：一份订阅同一时刻绑定一台电脑，换机先在旧机退出授权再到新机激活。
- **续费顺延**：未到期续费从当前到期日顺延叠加，而不是从付款日重算。
- **换机额度**：滚动一年内最多换机 6 次，同机重装不计入次数。
- **不强制联网**：仅首次激活、续费、换机时需联网核销，平时断网也能正常使用。
